1. Array

Digunakan untuk menyimpan banyak data dalam satu variabel dan bisa diolah dengan method seperti push, map, filter, dll.

2. BigInt

Tipe data untuk bilangan bulat yang sangat besar (lebih dari batas Number biasa).

3. Boolean

Mewakili nilai logika: true atau false, sering dipakai dalam kondisi (if).

4. Date

Digunakan untuk mengelola waktu dan tanggal, seperti mengambil tahun, bulan, jam, dll.

5. Encode / Decode

encodeURIComponent dan decodeURIComponent dipakai untuk mengamankan teks saat dikirim lewat URL.

6. Eval

Menjalankan kode JavaScript yang ditulis dalam bentuk string (harus hati-hati karena berisiko keamanan).

7. JSON

Digunakan untuk mengubah object ↔ teks JSON dengan JSON.stringify() dan JSON.parse().

8. Map

Struktur data key–value yang lebih fleksibel daripada Object, karena key bisa tipe apa saja.

9. Math

Berisi fungsi matematika seperti sqrt, pow, random, PI, dll.

10. Number

Objek untuk mengelola angka, termasuk pembulatan, cek integer, dll.

11. Object

Dasar dari hampir semua struktur data di JavaScript, menyimpan properti dan method.

12. Proxy

Digunakan untuk mengontrol akses ke sebuah object (misalnya validasi, logging, dll).

13. Reflect

API untuk memanipulasi object secara aman dan konsisten.

14. RegExp

Digunakan untuk pencarian pola teks (validasi email, password, dll).

15. sample.json

Contoh file JSON sebagai format pertukaran data yang ringan dan mudah dibaca.

16. Set

Struktur data untuk menyimpan nilai unik (tidak boleh ada duplikat).

17. String

Digunakan untuk mengolah teks: toUpperCase, includes, replace, dll.

18. Symbol

Tipe data unik yang biasanya dipakai sebagai key agar tidak bentrok dengan properti lain.
